# Ручная проверка КР №2

Проверено 6 октября 2026 года на Windows, Java 21 и Docker Desktop.
Новые unit/integration-тесты не добавлялись, существующие тесты не запускались.

| Проверка | Результат |
| --- | --- |
| `mvnw.cmd install -DskipTests` | Все 15 проектов Maven reactor собраны и установлены |
| Docker-сборка | Собраны восемь образов Java-сервисов/утилит через Maven Wrapper |
| Docker-запуск | Работают 11 контейнеров, существующие тома сохранены |
| JavaFX | Обычный запуск `javafx:run`, FXML и CSS загружаются без ошибок |
| Каталог в GUI | Произведения загружаются; поиск «Теремок» оставляет одну строку; выбор строки активирует действия |
| Окно записи в GUI | Загружаются роли, фрагменты и текст; интерфейс помещается в окно |
| Статистика в GUI | Отображаются пять карточек с данными backend |
| Excel в GUI | Есть пять чекбоксов сервисов и сохранение через FileChooser |
| Регистрация/вход/выход через API | Регистрация возвращает сеанс сразу; срок токена — семь дней; вход и logout работают |
| Загрузка черновика | Синтетический WAV загружен; скачанный исходник имеет тот же SHA-256 |
| Доступ к аудио | Без JWT — 401; чужой черновик и чужой результат рендера — 404 |
| Публикация | Два выбранных фрагмента опубликованы как целая роль; появилась опубликованная озвучка |
| Общая сборка | Выбраны опубликованные роли другого пользователя; FFmpeg завершил задание; скачан MP3 длительностью 0,6 с |
| Сборка по сегментам | Задание завершено; скачаны два MP3 |
| REST-логика клиента | Вручную вызваны методы RestApi для входа, каталога, текста, загрузки, скачивания, удаления своего тестового варианта, статистики, Excel и выхода |
| Выборочная выгрузка | Auth + catalog: пять листов с учётом `_export_status`, ноль ошибок; отдельно проверена выгрузка черновиков через RestApi клиента |
| Полная CLI-выгрузка | 25 таблиц, ноль ошибок |
| Ошибочный выбор сервисов | Неизвестный сервис и пустой выбор возвращают 400; запрос статистики без JWT — 401 |

Для проверки звукового конвейера использовался сгенерированный FFmpeg WAV,
а не запись с реального микрофона. В локальной БД оставлены учебный аккаунт,
опубликованная роль и задания рендера; исходные данные проекта не удалялись.
Файлы проверки находятся в игнорируемых `data/verification/` и `exports/`.

## Что ещё проверить вручную

- Доступ к настоящему микрофону, качество записи и фактический вывод звука.
- Полный пользовательский сценарий через GUI: запись/загрузка → выбор каждого
  фрагмента → публикация → выбор ролей → сборка → сохранение.
- Системный FileChooser: выбор пути, отмена и подтверждение перезаписи файла.
- Поведение при выключенном backend и истёкшем токене.

Проверка окон выполнена с локальным диагностическим запуском рабочего экрана;
вход проверялся через API. Диагностический запуск не входит в исходники клиента.
Это ручная проверка отдельных сценариев, не утверждение о полном покрытии GUI.
