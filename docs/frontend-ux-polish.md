# Полировка интерфейса — 31 октября 2026

Использован [Vercel Web Design Guidelines](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines):
семантические элементы, клавиатура, видимый фокус, ошибки рядом с полями,
предсказуемые состояния загрузки, URL для фильтров, reduced motion.

- Профиль и выход перенесены в раскрывающееся меню пользователя справа наверху.
  Удалены подпись с точкой и нижние действия сайдбара. Меню поддерживает стрелки,
  Home/End, Escape, Tab, закрытие снаружи и возврат фокуса.
- Каталог получил явный режим выбора, выбор диапазона через Shift, промежуточное
  состояние чекбокса страницы, закреплённую панель и счётчик. Выбор сохраняется
  между страницами и сортировками. Изменение условий поиска снимает его с пояснением.
  После массовой операции неуспешные UUID остаются выбранными с отдельными ошибками.
- Поиск отложен на 350 мс, устаревшие запросы отменяются и не перезаписывают новые.
  Коллекции не запрашиваются повторно на каждой странице. Во время обновления
  сетка остаётся на месте. Фильтры/сортировка/страница отражаются в URL.
- Кнопки получили hover/active/focus, уменьшение при нажатии и состояния ожидания.
  Зарезервировано место под скроллбар, повышен контраст подписей и светлой обложки.
  Используются официальные Hugeicons; reduced motion отключает анимацию.
- Ошибки основных форм показываются возле полей; фокус переходит к первой ошибке.
  Проверяются пробельные значения, числовые диапазоны, теги, политика пароля
  и совпадение повторного пароля. Вход имеет переключатель видимости пароля.
  При уходе из изменённой формы произведения запрашивается подтверждение.
- Карточка возвращает пользователя к прежним фильтрам каталога. Архивирование
  показывает результат на месте и позволяет восстановить книгу. Подтверждения
  используют native dialog с возвратом фокуса.
- Редактирование заметки получает фокус, сохраняет черновик новой заметки;
  добавление/изменение/удаление имеют состояния ожидания и сообщения результата.

## Уточнение импорта и экспорта

Веб-страница теперь называется «Экспорт данных», без импорта.
Excel доступен всем авторизованным ролям, все разделы выбраны по умолчанию.
Все колонки сохраняются, длинные значения продолжаются в колонках `[2]`, `[3]`.
По разделу 11 задания таблицы `auth_audit` и `library_audit` доступны только
администратору. CSV содержит все поля произведения и учитывает фильтры.
Импорт выполняется [консольным импортёром](console-import.md).
