# Визуальное направление веб-клиента

Подтверждено пользователем 30 октября 2026. Референсы по характеру: VK, MangaLib, Fable.

Интерфейс библиотеки для ПК: светлый фон, спокойный зелёный акцент, фиксированная
навигация слева, на главной — сетка произведений. Название «Теремок» сохраняется,
оформление рассчитано на взрослую аудиторию. Язык интерфейса — русский.

Палитра: фон `#F5F6F7`, поверхности `#FFFFFF`, текст `#252B2C`, акцент
`#39794B`, выделение `#EDF5EF`, границы `#E5E9E8`. Состояния выделяются цветом
и текстовой подписью одновременно. Главный контент выровнен по левому краю.

Шрифт интерфейса — Golos Text с поддержкой кириллицы; запасной — Segoe UI.
В типографических обложках используется Georgia. Обложки создаются в CSS
из настоящих названия и автора; сгенерированные растровые изображения не используются.
Системные пиктограммы — официальный набор Hugeicons Stroke Rounded.

На первом экране нет рекламного блока: поиск и произведения доступны сразу.
Элементы управления сгруппированы по задаче. Анимация ограничена короткой
реакцией на действие; `prefers-reduced-motion` учитывается.

Запись сохраняет сценарий JavaFX: выбор роли, выбор реплики, несколько дублей,
прослушивание, явный выбор дубля каждой реплики, публикация полной роли.
Уровень микрофона, звуковая волна и обрезка не включаются.

Источники:

- [Anthropic frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)
- [Hugeicons для Svelte](https://hugeicons.com/docs/integrations/svelte/quick-start)

Скилл использован как руководство по предметному дизайну и самопроверке.
Приоритет имеют требования пользователя и задание КР №3.
