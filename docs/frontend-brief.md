## Что обнаружено в проекте

Исследованы README, javafx-client/README.md, REST-контроллеры сервисов,
контракты backend-client-shared и JavaFX RestApi. Приложение не запускалось;
работоспособность и соответствие заданию по Moodle пока не проверены.

- Репозиторий: Programming-of-corporate-systems-MIREA, Maven multi-module,
  Java 21. Существующие клиенты: JavaFX и консольный. Отслеживаемых файлов
  Svelte и package.json не обнаружено.
- Предметная область: совместное озвучивание произведений по ролям.
- Backend: auth, catalog, text-work-content, draft-recordings, recordings,
  renderer, database-exporter/export-api. Traefik — HTTP-вход localhost:8080;
  PostgreSQL, Kafka, MinIO, FFmpeg; локальный запуск через Docker Compose.
- Сценарии текущего JavaFX-клиента: вход/регистрация; каталог с поиском,
  фильтрами и сортировкой; запись или загрузка нескольких дублей реплики;
  выбор дублей и публикация полной роли; выбор опубликованных ролей разных
  пользователей; асинхронная сборка MP3 целиком или по сегментам;
  прослушивание/скачивание; статистика; Excel по выбранным сервисам.
- Текущий клиент хранит JWT в памяти. README указывает срок JWT семь дней.
- Каталог и содержимое предоставляют операции чтения. Полного CRUD каталога
  в просмотренных контроллерах нет; наполнение идёт через deployer/Kafka.
- В просмотренном API recordings есть создание сборки и запрос по её UUID,
  но нет списка сборок пользователя. В просмотренных контроллерах нет
  голосования и API редактирования профиля. Не обещать такие экраны без
  согласования дополнительных backend-изменений.
- javafx-client/README.md прямо фиксирует согласованное отступление от
  буквального задания КР №2: без прямого JDBC, полного CRUD и экспорта
  отфильтрованной таблицы. Текущий Moodle-текст недоступен; нельзя считать,
  что это именно то же задание или что исключения действуют для новой работы.
- Внешний docs/architecture.md — черновой план: часть имён сервисов,
  маршрутов и функций расходится с текущим кодом. Для вопросов о существующих
  возможностях использованы текущие исходники и README репозитория.

## Вопросы к пользователю

1. Каков полный текст Moodle-задания, критерии оценки, требования из вложений
   и срок сдачи?
2. Веб-клиент заменяет JavaFX как основной интерфейс или добавляется рядом?
3. Для этой работы действуют прежние договорённости о REST вместо прямого
   JDBC, отсутствии полного CRUD и Excel по сервисам, или нужно буквально
   выполнить новое задание?
4. Нужны все существующие сценарии JavaFX, включая статистику и Excel, или
   есть конкретный обязательный набор для первой сдачи?
5. Можно ли будет менять backend, если понадобятся история сборок, профиль,
   голосование или CRUD, либо работаем строго с существующим API?
6. Для кого интерфейс в первую очередь: начинающих чтецов, опытных актёров
   озвучки или преподавателя, проверяющего работу?
7. Какое направление ближе: литературная библиотека, студия звукозаписи
   или спокойное функциональное приложение? Какие ощущения оно должно вызывать?
8. Какие 2–3 сайта/приложения нравятся визуально и что именно в них нравится?
   Какие приёмы и примеры категорически не подходят?
9. Сохраняем название «Теремок»? Нужны ли сказочные мотивы, обложки,
   иллюстрации или более взрослое оформление? Есть ли готовые материалы?
10. Нужна светлая, тёмная тема или обе? Есть ли предпочтения по цветам,
    шрифтам и анимациям?
11. Каталог удобнее как карточки произведений, таблица с плотными данными
    или переключение между двумя видами?
12. Запись удобнее пошагово по одной реплике или в рабочем пространстве
    со сценарием, списком реплик и дублями? Нужны ли таймер, уровень
    микрофона, волна и обрезка аудио, либо достаточно записи и прослушивания?
13. Что должно быть на первом экране после входа? Статистику и Excel
    показывать в основной навигации или вынести в служебный раздел?
14. На каких устройствах и браузерах будут пользоваться и защищать работу?
    Нужна ли полноценная запись с телефона? Интерфейс только на русском?
15. Вход должен сохраняться после обновления страницы и закрытия браузера?
16. Предпочтительны собственные компоненты и CSS или допустима готовая
    Svelte-библиотека компонентов с индивидуальным оформлением?
17. Как сдаём и запускаем веб-клиент: локально отдельной командой, вместе
    с backend в Docker Compose или на опубликованном сервере? Нужны ли
    отчёт, скриншоты, демонстрационные данные и инструкция для защиты?

## Подтверждённые ответы пользователя

- Веб-клиент добавляется рядом с JavaFX, сохраняются все существующие сценарии.
- Выполнить КР №3 по заданию; backend разрешено дорабатывать.
- Учебный проект; референсы VK, MangaLib, Fable.
- Название «Теремок», взрослое оформление, официальные иконки Hugeicons.
- Только светлая тема, зелёный акцент, сетка книг на главной, навигация слева.
- Статистика и Excel — отдельные ссылки в меню.
- Только ПК, русский интерфейс; вход сохраняется между посещениями.
- Сценарий записи JavaFX устраивает; без уровня микрофона, волны и обрезки.
- Компоненты и оформление выбирает исполнитель.
- Проверить работу и делать скриншоты; допускаются Edge и встроенный браузер.
