# Ручная проверка звука

Автоматические тесты подменяют микрофон и динамик фейками. Реальный звуковой
тракт проверяется руками — один раз после Task 15 и после любых правок в пакете
`audio`.

Запуск: `./gradlew run`

1. Создать профиль, выбрать «Озвучить книгу» → «Красная Шапочка» → «Мама».
2. Начать запись, сказать реплику вслух, остановить.
3. Прослушать: голос слышен, обрывов нет, тишины в начале и в конце немного.
4. Перезаписать ту же реплику, прослушать снова — играет новая версия.
5. Опубликовать роль в «Моих озвучках».
6. Сменить профиль, выбрать «Слушать книгу» → «Красная Шапочка» → «Слушать».
   Озвученная реплика звучит, остальные читаются текстом с паузой.
7. Во время воспроизведения нажать Enter — оно останавливается сразу.
8. Проверить лимит: начать запись и не останавливать 2 минуты. Запись
   прекращается сама, файл сохраняется и проигрывается.
9. Отключить микрофон в системе и попробовать записать: появляется понятное
   сообщение, приложение не падает, черновик цел.
10. Проверить размер: `ls -la data/voicings/*/` — файл 5-секундной реплики
    примерно 160 КБ.
