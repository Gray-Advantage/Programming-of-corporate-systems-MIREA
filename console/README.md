# Теремок — консольная версия

Консольное приложение для озвучивания книг по ролям. Записываете голосом реплики
персонажа, публикуете роль, а другие профили собирают из чужих ролей свою версию
книги, слушают её и голосуют.

## Что нужно

- **JDK 21.** На macOS: `brew install openjdk@21`, на Windows:
  `winget install EclipseAdoptium.Temurin.21.JDK`.
- **Микрофон и колонки** — для записи и прослушивания. Без микрофона приложение
  запускается, но записать реплику не получится.

## Запуск на macOS

Все команды выполняются из папки `console/`.

### 1. Укажите JAVA_HOME

Формула `openjdk@21` не добавляет `java` в PATH, а системный `/usr/bin/java` на
macOS — заглушка, которая сама по себе не работает. Поэтому без `JAVA_HOME` не
стартует даже `./gradlew`: он падает с ошибкой «Unable to locate a Java Runtime».

    export JAVA_HOME="$(brew --prefix openjdk@21)/libexec/openjdk.jdk/Contents/Home"

Чтобы не вводить это каждый раз, добавьте строку в `~/.zshrc`. На другой ОС
укажите в `JAVA_HOME` путь к своему JDK 21.

В `gradle.properties` прописан путь к JDK на машине автора
(`org.gradle.java.installations.paths`). Если у вас JDK лежит в другом месте,
поправьте путь там.

### 2. Запустите

    ./gradlew -q --console=plain run

Флаги `-q --console=plain` убирают служебный вывод Gradle, иначе он смешивается с
меню приложения. Первый запуск скачивает Gradle и собирает проект — это может
занять до минуты.

### Запуск без Gradle

Можно один раз собрать готовый скрипт запуска и дальше вызывать его напрямую —
так приложение стартует быстрее. `JAVA_HOME` для него тоже нужен.

    ./gradlew installDist
    build/install/teremok/bin/teremok

### Микрофон на macOS

При первой записи macOS спросит, можно ли программе-терминалу (Терминал, iTerm и
т. п.) пользоваться микрофоном. Если не разрешить, запись получится пустой.
Разрешение меняется в «Системные настройки → Конфиденциальность и безопасность →
Микрофон».

## Запуск на Windows

Команды выполняются в PowerShell из папки `console`.

### 1. Проверьте Java

    java -version

Должна быть версия 21. Установщик Temurin добавляет `java` в `PATH`, и тогда больше
ничего настраивать не нужно. Если команда не находится или показывает другую
версию, укажите папку JDK 21 в `JAVA_HOME`:

    $env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\<папка jdk-21>"

Так переменная действует только в текущем окне. Чтобы задать её насовсем,
используйте «Переменные среды» в настройках Windows.

### 2. Соберите и запустите

    .\gradlew.bat installDist
    .\build\install\teremok\bin\teremok.bat

В `cmd` те же команды пишутся без `.\`. Первая сборка скачивает Gradle и может
занять до минуты.

Gradle может предупредить, что папки из `org.gradle.java.installations.paths` не
существует (`Directory '/opt/homebrew/...' ... does not exist`). Это путь к JDK на
машине автора из `gradle.properties`, на сборку он не влияет.

### Кодировка

Приложение берёт кодировку у консоли, поэтому кириллица выводится и вводится
правильно без `chcp`. В стандартной кодировке консоли Windows (cp866) нет длинного
тире, кавычек-«ёлочек» и значка ●, поэтому они выводятся как `-`, `"` и `*`.

### Микрофон

«Параметры → Конфиденциальность и защита → Микрофон»: включите доступ к микрофону
и пункт «Разрешить классическим приложениям доступ к микрофону». Без этого
записать реплику не получится.

## Тесты

macOS:

    ./gradlew test

Windows:

    .\gradlew.bat test

Полный прогон занимает несколько секунд.

## Как пользоваться

Пункты меню выбираются номером и Enter. Короткий сценарий, чтобы попробовать всё:

1. `n` — создать профиль. Имя: буквы, цифры, дефис и подчёркивание, без пробелов.
2. `2` «Озвучить книгу» → книга → персонаж. Enter начинает запись, Enter
   останавливает. Дальше `1` — прослушать, `2` — перезаписать, `3` — следующая
   реплика.
3. `3` «Мои озвучки» → роль → `3` «Опубликовать». Опубликовать можно только роль,
   у которой записаны все реплики. Чтобы опубликовать разом все такие роли, в
   списке «Моих озвучек» нажмите `a` — «Опубликовать все готовые».
4. `4` «Сменить профиль» → создать второй профиль.
5. `1` «Слушать книгу» → книга. Персонажам автоматически назначаются лучшие
   опубликованные озвучки, остальные читаются текстом. `s` — слушать, Enter во
   время воспроизведения — остановить.

На экране книги `n` открывает выбор голоса для персонажа. Там работают команды:

| Команда | Действие |
| --- | --- |
| номер | выбрать эту озвучку |
| `p N` | прослушать пример озвучки N |
| `l N` | лайк; повторно — снять голос |
| `d N` | дизлайк; повторно — снять голос |
| `t` | читать этого персонажа текстом |
| `0` | назад |

`0` везде означает «назад». Ctrl+D (конец ввода) работает так же и выводит из
приложения.

## Как устроено

- Книги встроены в приложение: `src/main/resources/books/*.txt`.
- Формат книги — заголовок, строка `---`, дальше реплики вида `Имя: текст`.
- Единица публикации — роль: один персонаж, озвученный одним автором.
- Рейтинг роли — лайки минус дизлайки. За свою роль голосовать нельзя.
- Реплики без озвучки читаются текстом, поэтому книгу всегда можно прослушать
  целиком.

## Данные

Всё хранится в каталоге `data/` в папке, из которой запущено приложение. При
запуске из папки `console` это `console/data/`.

    data/profiles.txt                  список профилей
    data/voicings/<роль>/meta.txt      книга, персонаж, автор, статус, дата
    data/voicings/<роль>/votes.txt     голоса
    data/voicings/<роль>/line-0007.wav запись реплики №7

Каталог можно удалить целиком — приложение создаст его заново, но все профили и
записи пропадут.

## Ограничения

- Всё локально: сети нет, профили живут на одной машине.
- Формат звука только WAV, 16 кГц, моно.
- Текст выпущенной книги менять нельзя: номера реплик привязаны к нему.
- Приложение рассчитано на один запущенный экземпляр.
