# Теремок — консольная версия

Консольное приложение для озвучивания книг по ролям. Записываете голосом реплики
персонажа, публикуете роль, а другие профили собирают из чужих ролей свою версию
книги, слушают её и голосуют.

## Требования

- **JDK 21** — именно JDK, а не только JRE.
- **Микрофон и устройство вывода звука** — для записи и прослушивания. Без
  микрофона приложение запустится, но записать реплику не получится.
- Подключение к интернету при первой сборке — Gradle Wrapper скачивает Gradle и
  тестовые зависимости.

Проверьте установленную Java:

    java -version
    javac -version

Обе команды должны показывать версию 21.

## Установка JDK 21

### Windows

В PowerShell или Windows Terminal:

    winget install EclipseAdoptium.Temurin.21.JDK

После установки откройте новое окно терминала и снова выполните `java -version`.

### macOS

Через Homebrew:

    brew install openjdk@21
    export JAVA_HOME="$(brew --prefix openjdk@21)/libexec/openjdk.jdk/Contents/Home"

Чтобы `JAVA_HOME` устанавливался автоматически, добавьте вторую команду в
`~/.zshrc`.

### Linux

Ubuntu и Debian:

    sudo apt update
    sudo apt install openjdk-21-jdk

Fedora:

    sudo dnf install java-21-openjdk-devel

В других дистрибутивах установите пакет OpenJDK 21 средствами своего пакетного
менеджера.

## Сборка и запуск

Все следующие команды выполняются из папки `console/`. Если вы находитесь в корне
репозитория, сначала перейдите в неё:

    cd console

### Windows — PowerShell

Соберите дистрибутив и запустите приложение:

    .\gradlew.bat installDist
    .\build\install\teremok\bin\teremok.bat

В обычном `cmd.exe` команды те же, но их можно вводить без префикса `.\`.

### macOS и Linux

    ./gradlew installDist
    ./build/install/teremok/bin/teremok

Если после распаковки архива оболочка сообщает `Permission denied`, верните
Gradle Wrapper право на выполнение и повторите сборку:

    chmod +x gradlew

Первый запуск `installDist` скачивает Gradle и зависимости, поэтому занимает
больше времени. Последующие запуски выполняются сразу готовым скриптом из
`build/install/teremok/bin/`.

Для разработки приложение можно запустить непосредственно через Gradle:

macOS и Linux:

    ./gradlew -q --console=plain run

Windows:

    .\gradlew.bat -q --console=plain run

## Настройка JAVA_HOME

Обычно установщик или пакетный менеджер настраивает Java автоматически. Если
Gradle выбирает другую версию, явно укажите каталог JDK 21.

Windows, только для текущего окна PowerShell:

    $env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\<папка jdk-21>"

Linux, если `javac` уже указывает на нужный JDK:

    export JAVA_HOME="$(dirname "$(dirname "$(readlink -f "$(command -v javac)")")")"

macOS с Homebrew:

    export JAVA_HOME="$(brew --prefix openjdk@21)/libexec/openjdk.jdk/Contents/Home"

В `gradle.properties` указан дополнительный путь к JDK на машине автора. На
Windows и Linux Gradle может вывести предупреждение, что `/opt/homebrew/...` не
существует. Оно не мешает сборке, если `java -version` и `javac -version`
показывают версию 21.

## Кодировка терминала

Приложение использует кодировку подключённого терминала. На macOS и Linux это
обычно UTF-8. На Windows кириллица также работает без ручного вызова `chcp`.

В старой консоли Windows с кодировкой CP866 нет длинного тире, кавычек-«ёлочек» и
значка `●`. Приложение автоматически заменяет их на `-`, `"` и `*`. Для полного
набора символов используйте Windows Terminal или PowerShell с UTF-8.

## Доступ к микрофону

### Windows

Откройте «Параметры → Конфиденциальность и защита → Микрофон» и включите доступ к
микрофону, включая пункт «Разрешить классическим приложениям доступ к микрофону».

### macOS

При первой записи разрешите доступ программе-терминалу. Позже разрешение можно
изменить в «Системные настройки → Конфиденциальность и безопасность → Микрофон».

### Linux

Убедитесь, что микрофон не выключен в настройках звука и выбран как устройство
ввода по умолчанию. Приложению нужен работающий звуковой сеанс ALSA, PulseAudio
или PipeWire. В headless-системах, контейнерах и WSL аудиоустройства обычно нужно
настраивать отдельно.

## Тесты

macOS и Linux:

    ./gradlew test

Windows:

    .\gradlew.bat test

Для тестов реальные микрофон и колонки не нужны. Полный прогон занимает несколько
секунд.

Если на Windows компиляция проходит, но тесты завершаются множеством ошибок
`ClassNotFoundException`, проверьте путь к репозиторию. Некоторые версии Gradle
некорректно формируют classpath при кириллице в абсолютном пути. В таком случае
переместите или заново клонируйте репозиторий, например в `C:\dev\teremok`.

## Как пользоваться

Пункты меню выбираются номером и Enter. Короткий сценарий, чтобы попробовать всё:

1. `n` — создать профиль. Имя: буквы, цифры, дефис и подчёркивание, без пробелов.
2. `2` «Озвучить книгу» → книга → персонаж. Enter начинает запись, Enter
   останавливает. Дальше `1` — прослушать, `2` — перезаписать, `3` — следующая
   реплика.
3. `3` «Мои озвучки» → роль → `3` «Опубликовать». Опубликовать можно только роль,
   у которой записаны все реплики. Чтобы опубликовать разом все такие роли, в
   списке «Моих озвучек» нажмите `a` — «Опубликовать все готовые».
4. `4` «Сменить профиль» → создать второй профиль.
5. `1` «Слушать книгу» → книга. Персонажам автоматически назначаются лучшие
   опубликованные озвучки, остальные читаются текстом. `s` — слушать, Enter во
   время воспроизведения — остановить.

На экране книги `n` открывает выбор голоса для персонажа. Там работают команды:

| Команда | Действие |
| --- | --- |
| номер | выбрать эту озвучку |
| `p N` | прослушать пример озвучки N |
| `l N` | лайк; повторно — снять голос |
| `d N` | дизлайк; повторно — снять голос |
| `t` | читать этого персонажа текстом |
| `0` | назад |

`0` везде означает «назад». Ctrl+D (конец ввода) работает так же и выводит из
приложения.

## Как устроено

- Книги встроены в приложение: `src/main/resources/books/*.txt`.
- Формат книги — заголовок, строка `---`, дальше реплики вида `Имя: текст`.
- Единица публикации — роль: один персонаж, озвученный одним автором.
- Рейтинг роли — лайки минус дизлайки. За свою роль голосовать нельзя.
- Реплики без озвучки читаются текстом, поэтому книгу всегда можно прослушать
  целиком.

## Данные

Всё хранится в каталоге `data/` в папке, из которой запущено приложение. При
запуске из папки `console` это `console/data/`.

    data/profiles.txt                  список профилей
    data/voicings/<роль>/meta.txt      книга, персонаж, автор, статус, дата
    data/voicings/<роль>/votes.txt     голоса
    data/voicings/<роль>/line-0007.wav запись реплики №7

Каталог можно удалить целиком — приложение создаст его заново, но все профили и
записи пропадут.

## Ограничения

- Всё локально: сети нет, профили живут на одной машине.
- Формат звука только WAV, 16 кГц, моно.
- Текст выпущенной книги менять нельзя: номера реплик привязаны к нему.
- Приложение рассчитано на один запущенный экземпляр.
